# SQL Island Reflection

### 1. What have you learned about databases and SQL so far, just by playing?
I learned that databases store information in structured lists and that SQL commands act as precise questions/Unique methods to retrieve only the specific data needed to advance or solve problems in the game.

### 2. Which SQL commands and patterns did you actually use?
I used basic `SELECT` statements to retrieve data, `FROM` to specify the table, and `WHERE` filters to narrow down results based on specific conditions.

### 3. In your own words — after playing — what is a table, a row, a column, and a query?
- Table: An organized container or spreadsheet like sheet that holds a specific type of data (like villagers or items).
- Row: A single, complete entry or record inside a table (like information about one specific person).
- Column: A specific category or attribute shared by all rows (like a person's name or profession).
- Query: A question or command written in SQL telling the database what data to find and display.

### 4. What surprised you? What is still confusing?
It was surprising how intuitive it feels to interact with a database through a story-driven game. Understanding how different tables connect together is still a bit tricky, but playing makes it much clearer. Additionally repeatitive sytax errors and strict distinction between upper case and lower case use made it slighty tricky in navigating the SQL language.
