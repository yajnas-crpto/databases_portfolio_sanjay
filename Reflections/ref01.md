# Reflection 1 in Module 1
### Key Take-Away & Advice

-Key Take-Away: A database is not just a massive server managed by an IT department; it can be an embedded file that lives directly inside an application's process. Understanding that local-first tools (like SQLite and DuckDB) eliminate the overhead of cloud infrastructure changes how software interacts with storage.

-Advice: Do not let the initial tooling overwhelm you. Setting up Git, VS Code, and new toolchains like `uv` all at once is genuinely frustrating when you are staring at it for the first time. Take it one step at a time, rely on your documentation, and don't hesitate to use AI assistants to break down confusing error messages.
