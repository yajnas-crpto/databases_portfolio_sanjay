# Reflection 1 in Module 1

### Key Take-Away & Advice

- **Key Take-Away:** I learned that a database does not always need to be managed by a large server or stored in the cloud. Tools such as SQLite and DuckDB can run locally as part of an application. This helped me understand the idea of local-first databases and how they can make applications simpler.
- **Advice:** Do not let the initial setup overwhelm you. Take your time with Git, VS Code, and tools like `uv`. If you run into errors, read the messages carefully, check the documentation, and use AI to help you understand what went wrong.
